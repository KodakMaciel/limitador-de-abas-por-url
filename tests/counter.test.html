Abra por chrome-extension://<ID>/tests/counter.test.html. Em file:// o navegador bloqueia módulos ES.

Os módulos não carregaram. Copie o ID em chrome://extensions e abra chrome-extension://<ID>/tests/counter.test.html.

Esta página usa somente funções puras de counter.js, com abas de mentira. Ela não chama nenhuma API do Chrome e por isso não pode fechar, abrir ou navegar aba nenhuma. O motor completo (background.js) é verificado fora do navegador, com o chrome simulado.
